# 墨坞 Inkdock

本地优先的小说创作工作台。写完，再写好。

墨坞用一本书、一卷、一章的真实结构承载长篇写作，正文保持纯文本；服务端自动保存、浏览器草稿兜底和冲突保护共同保证不丢字。内置安卓手机预览，以 CSS 多栏真实排版模拟起点、番茄、晋江、微信读书、七猫五种阅读界面的排版与翻页手感。

当前状态：**M1 已完成并通过浏览器验收；自定义书封与故事设定已交付（2026-10-23）**。下一阶段是 M1.5 手感打磨，长期规划见 [docs/04-roadmap.md](docs/04-roadmap.md)。

## 功能

### 书架

- 今日新增、累计字数、连载作品、章节数聚合。
- 继续写作直达最近编辑章节。
- 状态筛选、书名/题材搜索、新建作品。
- 桌面侧边栏与移动端胶囊底栏统一导航。

### 作品与目录

- 作品资料编辑、题材与目标字数。
- 自定义书封：JPG / PNG / WebP 自动裁剪为 4:5 并压缩；无图时使用平涂底色与书名版式。
- 分卷、卷内新增章节、章节状态（草稿 / 待发布 / 已发布）。
- 删除章节软删除，空卷才可删除，写入时校验卷与作品归属。
- 单作品导出纯文本 TXT 或 Markdown。

### 写作编辑器

- 900 ms 防抖自动保存；持续输入每 20 s 强制保存；离开页面前补交。
- 每次输入同步写 `localStorage` 草稿，服务端确认后清理；刷新可恢复未同步草稿。
- 携带 `baseUpdatedAt` 的乐观锁；版本不一致返回 409，由作者选择保留本地或载入远端。
- 离线时显示「离线，已存本机」，恢复网络后自动补交。
- 失败的保存按 6 s / 12 s / 24 s 指数退避，封顶 30 s。
- 服务端重算字数、段落、当日新增字数，并创建版本快照（距上次超过 15 分钟时自动；手动快照目前提供 API，版本历史界面在 M1.5）。
- 专注模式、章节目录抽屉、写作状态与每日目标、正文字体与字号记忆。
- 故事设定侧栏：角色、组织、地点、物品、概念五类；搜索、筛选、详情、新建与编辑。
- 宽屏停靠「故事设定」标签页，窄屏打开右侧抽屉；切换面板不打断正文与草稿。
- AI 侧栏：续写、润色、起名、大纲。密钥只留在服务端；未配置时明确说明，不伪造结果。

### 手机预览

- 393 × 852 安卓设备比例，桌面等比缩放，移动端自适应。
- 五种平台皮肤，各有独立默认字体、字号、行高、页边距、页眉页脚与品牌色。
- CSS multi-column 真实分页，字号、行高、边距、字体变化即时重排。
- 点击左右区域、横向滑动、方向键、空格、PageUp/PageDown 翻页。
- 末页翻入下一章，首页回退上一章末页；目录可跨章跳转。
- 每个平台独立记忆阅读设置；阅读主题、翻页动画、进度展示均可调。
- 页面明确标注「界面模拟，非官方客户端」，不包含任何平台账号或真实互动功能。

### 设置

- 浅色 / 深色 / 跟随系统，首屏无闪烁。
- 修改笔名；每日目标本地保存；编辑器默认正文字体。
- AI 配置状态、数据文件位置与备份说明。
- 所有偏好按设备保存，不上传。

## 设计约束

- 视觉语言为安卓原生胶囊：完整圆角、分段控件、平涂色块、细线、留白。
- 不使用任何 CSS 渐变，不使用 emoji。
- 颜色只通过 `src/app/globals.css` 的语义令牌；平台品牌色集中在 `src/lib/platforms.ts`，书封与设定识别色集中在 `src/lib/constants.ts`。
- 桌面与手机共用同一套语义令牌，阅读器舞台固定深色，保证预览聚焦。
- 正文是纯文本；格式、平台排版属于发布与预览层，不进入内容事实层。
- 故事设定是写作参考，不写入正文、手机预览或导出文件。

## 启动

```bash
npm install
npm run dev
```

打开 http://localhost:3000 。首次启动会自动创建 `data/inkdock.db` 与两本示例作品（墨坞的种子数据只用于演示，可在界面中继续编辑）。

生产构建：

```bash
npm run build
npm run start
```

### AI（可选）

编辑器和预览不依赖 AI。需要 AI 建议时，在项目根目录创建 `.env.local`：

```dotenv
AI_BASE_URL=https://api.openai.com/v1
AI_API_KEY=your-key
AI_MODEL=gpt-4o-mini
```

- 任意兼容 `POST /chat/completions` 的服务均可。
- `AI_API_KEY` 是启用条件；`AI_BASE_URL` 与 `AI_MODEL` 有默认值。
- 修改环境变量后需重启开发服务器。
- 密钥只在服务端读取，不进入客户端 bundle、页面或日志。
- 未配置时接口返回 501 和可行动的配置提示，界面不会显示伪造的生成内容。

## 数据

- 默认位置：`data/inkdock.db`，已加入 `.gitignore`。
- 可用 `INK_DB_PATH` 指向其他 SQLite 文件。
- 启用 WAL，单进程写入；备份前先停止服务器，再复制数据库文件。
- 章节与作品为软删除；卷只能在无未删除章节时删除，删除卷会级联清除该卷内已归档章节。
- 自动保存与版本快照在同一事务内更新章节、作品时间与每日字数。
- 书封以压缩后的 data URL 存在 `works.cover_image`，单张解码后 ≤700 KB；服务端校验格式与文件头。
- 故事设定存 `story_entities`，按作品隔离；删除为硬删除，不改变正文与作品编辑时间。
- 迁移版本：`PRAGMA user_version = 2`（书封字段与故事设定表）。

## 自动保存语义

| 场景 | 行为 |
| --- | --- |
| 输入 | 立即写本地草稿；900 ms 后保存；持续输入每 20 s 强制保存 |
| 保存成功 | 更新基准时间、清理草稿、显示已保存 |
| 网络失败 | 6/12/24/30 s 退避重试；本地草稿保留 |
| 离线 | 显示「离线，已存本机」，恢复网络后立即补交 |
| 刷新 | 发现本地草稿与服务端不同则提示载入或丢弃 |
| 版本冲突 | 409 不静默覆盖；选择保留本地覆盖或载入远端 |
| 重复请求 | 到达时若远端正文与请求完全一致，按幂等成功处理，不误报冲突 |
| 页面关闭 | `pagehide` 时写草稿，并可 `sendBeacon` 补交 |
| 版本快照 | 正文变化且距上次超过 15 分钟自动快照；手动快照仅有 API，界面在 M1.5 |

## 验收与边界
