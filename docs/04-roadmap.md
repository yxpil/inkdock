## 2. M1 · 可用的单人写作工作台

状态：**完成（2026-10-22）**。验收证据见 [需求分析第 7 节](./00-requirements.md#7-m1-验收清单) 与 [上下文交接](./05-context-handoff.md#2-已验证基线2026-10-22)。

目标：一个作者可以真实写完并预览一章。

范围（已锁定）：

- 书架：统计、继续写作、筛选搜索、新建作品。
- 作品：资料编辑、分卷、章节增删改、字数、导出。
- 编辑器：纯文本、自动保存、本地恢复、字数、专注模式、大纲、状态、目标、AI 侧栏。
- 预览：安卓机身、五平台皮肤、真实分页、翻页、阅读设置、目录、跨章。
- 设置：主题、笔名、每日目标、AI 状态。
- 后端：SQLite schema、种子数据、作品/卷/章/保存/版本/导出/AI 接口。
- 文档：需求、设计、架构、数据、路线图、交接。

明确不做（M1 当时）：富文本、多人实时、账号登录、云同步、批注、拖拽排序、故事圣经、全文搜索。其中故事圣经与书封已在随后以增量交付，见 2.1。

验收：见 [需求分析第 7 节](./00-requirements.md#7-m1-验收清单)。

## 2.1 增量交付 · 书封与故事设定（2026-10-23 完成）

目标：让作品有可辨认的封面，并让角色、组织、地点、物品与概念在写作现场随手可查。

范围：

- 书封：新建/编辑作品上传 JPG/PNG/WebP，客户端 4:5 居中裁剪为 800×1000，服务端校验 data URL 与文件头；书架、作品页统一渲染；可更换、移除。
- 故事设定：五类实体 CRUD；名称、一句话标签、摘要、详细设定、识别色；搜索、类型筛选、详情。
- 编辑器接入：宽屏右侧标签页「故事设定」，窄屏右侧抽屉；与 AI 面板共用停靠区，切换不丢失草稿。
- 数据：`works.cover_image`、`story_entities`，迁移至 `user_version = 2`。
- 边界：设定不进入正文、预览与导出；封面仅存本地 SQLite，不接对象存储。

验收：

- 真实 Chrome 1440 / 390 宽度走通上传、刷新持久化、书架渲染、设定新建/编辑/筛选/详情/删除。
- 无效封面（错误格式、超大文件）被服务端拒绝；清空封面恢复底色版式。
- 390 宽抽屉 `scrollWidth = innerWidth = 390`；新建设定弹窗完整覆盖视口，不被抽屉裁切。
- `npm run typecheck`、`npm run build` 通过。

证据见 [上下文交接第 2 节](./05-context-handoff.md#2-已验证基线2026-10-23)。

## 3. M1.5 · 手感打磨（下一批）

优先级从高到低：

1. 版本历史界面：列表、字数差异、预览、恢复。
2. 章节拖拽排序与跨卷移动，重排时保持稳定。
3. 编辑器全文查找替换。
4. 打字机模式与段落聚焦。
5. 编辑器字体与行宽设置真正生效并可记忆。
6. 手机预览：目录定位当前章、阅读进度持久化、字号滑杆更细。
7. 书架：按最近编辑/字数/书名排序。
8. 加载骨架、错误边界、离线提示条。
9. 键盘快捷键面板。

验收：连续写作 1 小时无保存焦虑；所有列表操作有撤销或确认；手机端无溢出。

## 4. M2 · 协作地基与设定库

- 本机账号：登录、笔名、头像色、会话 cookie。
- 作品成员：邀请码、角色（owner/editor/commenter/reader）、成员列表。
- 权限：读写接口按成员角色校验；公开部署防护。
- 批注：选中文本 → 锚点批注 → 回复 → 解决。
- 故事设定深化：双向链接、时间线、伏笔视图；基础 CRUD 已提前交付。
- 回收站：作品/章节恢复与彻底删除。
- 版本界面完整化；自动备份与一键导出数据库。
- 全局搜索：作品、章节标题、正文（SQLite FTS5）。

验收：两名用户在同一局域网协作改稿，角色边界清晰；被移除成员无法读取。

## 5. M3 · 实时协作与 AI 增强

- Yjs 文档 + WebSocket 服务；章节级房间。
- 在线状态、光标与选区、正在编辑提示。
- 离线编辑合并；定期物化快照到 SQLite。
- 操作日志与按人筛选的历史。
- AI 流式输出、停止、重试、多候选。
- AI 上下文：当前章节 + 故事圣经 + 最近章节摘要；显式展示发送内容。
- AI 草稿标记与发布前提醒。
- 提示词模板管理与平台风格预设。

验收：两人同时输入无字符丢失；断网 5 分钟再连可合并；AI 输出可停止且不自动入正文。

## 6. M4 · 发布工作流与离线

- 平台格式检查：段落长度、章节字数、标题规范、敏感词提示（本地词表）。
- 分卷导出、章节批量导出、剪贴板格式。
- PWA：安装、离线阅读已缓存章节、后台补交保存。
- 写作统计：日/周/月、连续写作天数、目标完成度。
- 自动备份：每日 SQLite 副本，保留 7 份。
- 可访问性与移动端专项打磨。

验收：断网可打开最近作品并编辑；恢复后自动保存；导出可直接粘贴到目标平台。

## 8. 任务规范

### 8.1 任务粒度

一个任务应当：

- 在 0.5–2 小时内可完成；
- 有明确的用户可见结果；
- 有可执行的验收步骤；
- 不跨两个里程碑；
- 不依赖未决定的架构。

### 8.2 状态定义

| 状态 | 含义 |
| --- | --- |
| backlog | 已记录，未排期 |
| ready | 需求清楚，可开工 |
| in_progress | 正在做，且只有一项 |
| review | 代码完成，等待浏览器/构建验证 |
| done | 验收通过，文档同步 |
| dropped | 明确不做，记录原因 |

### 8.3 完成定义（DoD）

- 功能在真实浏览器中走通主路径与一个边界路径。
- `npm run typecheck` 通过；里程碑收尾时 `npm run build` 通过。
- 无新增硬编码颜色、渐变、emoji。
- 手机与桌面均无横向溢出。
- 文档中的接口、表结构、状态与实现一致。
- 如修改 UI，至少在 1440 宽与 390 宽截图检查。

## 11. 风险登记

| 风险 | 概率 | 影响 | 触发信号 | 应对 |
| --- | --- | --- | --- | --- |
| 范围膨胀导致 M1 延期 | 高 | 中 | 新需求未进 backlog 就直接开工 | 锁定 M1 范围；新想法写回本文档 |
| 自动保存边界遗漏 | 中 | 高 | 切换章节丢字 | 浏览器验证切换、刷新、断网、崩溃四场景 |
| 分页页数不准 | 中 | 中 | 最后一页空白/截断 | 用不同字号与平台逐页截图核对 |
| 平台模拟被认为官方客户端 | 低 | 中 | 用户误解 | 全站标注「界面模拟，非官方客户端」 |
| AI 供应商接口差异 | 中 | 中 | 配置后 4xx/5xx | 兼容 Chat Completions 标准；错误透明 |
| SQLite 锁竞争 | 低 | 中 | 保存报 SQLITE_BUSY | WAL + busy_timeout 5000；单进程写入 |
