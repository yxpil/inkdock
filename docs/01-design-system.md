# 墨坞 Inkdock · 设计系统

版本：0.4  
更新：2026-10-23  
适用范围：登录与注册、全部工作台页面、编辑器、手机预览。

---

## 1. 美学定位

**关键词：纸感、胶囊、留白、克制、触感明确。**

界面参考安卓原生（Material 3 式）的胶囊几何与层级逻辑，但去掉强烈的品牌色块和动效，形成「安静的书桌」：

- 背景像纸：暖灰白，不用纯白大面积铺底。
- 主要动作像实体按键：完整胶囊，明确按压反馈。
- 信息像铅字：层级靠字重、字号与留白，不靠装饰。
- 颜色只有一个主强调：松墨绿。其余颜色只服务于状态与平台模拟。

### 1.1 硬性禁止

1. 禁止任何 CSS 渐变（linear-gradient / radial-gradient / conic-gradient），包括封面、按钮、背景、加载态。
2. 禁止 emoji 作为图标、装饰或文案标点。全部使用线性 SVG 图标。
3. 禁止玻璃拟态、霓虹发光、3D 倾斜卡片、拟物纹理。
4. 禁止页面级硬编码颜色；平台模拟皮肤、书封、设定识别色与账号头像色除外，且必须集中在 `src/lib/platforms.ts` 与 `src/lib/constants.ts`。识别色与头像色上的文字统一使用 `--on-cover`。
5. 禁止仅靠颜色传达状态；必须同时有文字或图标。

## 2. 设计原则

1. **一屏一个主要动作**：主按钮只有一个，使用实心胶囊；其余为次要或幽灵胶囊。
2. **结构先于装饰**：书、卷、章用间距、编号、细线表达，不堆卡片阴影。
3. **触感明确**：按下缩放 0.98，过渡 120–180 ms；不使用夸张弹跳。
4. **预览可信**：手机预览的排版参数必须来自真实测量，不用估算页数。
5. **安静的错误处理**：错误出现在发生位置，文案说明下一步，不用红色大面积铺满。

## 5. 空间、圆角、层级、动效

### 5.1 间距

4 px 基准。常用：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56 / 80。  
页面左右内边距：桌面 40，平板 28，手机 20。内容最大宽度：工作台 1440，阅读正文 760，表单 560。

### 5.2 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| pill | 999 px | 按钮、标签、输入、导航选中药丸 |
| 2xl | 20 px | 小卡片、输入区 |
| 3xl | 28 px | 标准卡片、面板 |
| 4xl | 32 px | 对话框、抽屉 |
| device | 44 px | 手机外框 |

不使用 2–6 px 的「微圆角」，保持胶囊语言一致。

### 5.3 层级

平铺优先，阴影只用于浮层：

- 卡片：1 px 描边，`shadow-soft`（极轻）。
- 悬停：上移 2 px，描边加深。
- 对话框：背景遮罩 `ink/35` + 模糊 4 px；面板自身无投影或极轻投影。
- 不用彩色投影。

### 5.4 动效

| 场景 | 时长 / 曲线 |
| --- | --- |
| 按压 | 120 ms ease-out，scale 0.98 |
| 悬停 | 160 ms ease-out |
| 对话框 | 180 ms ease-out，opacity + scale 0.98→1 |
| 翻页 | 300 ms cubic-bezier(0.2, 0.7, 0.2, 1) |
| 保存状态 | 150 ms 颜色过渡 |

`prefers-reduced-motion` 下翻页改为瞬时切换，其余动效降为 0 ms。

## 6. 组件规范

### 6.1 胶囊按钮 Capsule

| 类型 | 高度 | 内边距 | 背景 | 文字 |
| --- | --- | --- | --- | --- |
| primary | 44 | 0 20 | accent | on-accent，14/500 |
| secondary | 40 | 0 16 | surface-2 | ink |
| outline | 40 | 0 16 | transparent + line | ink |
| ghost | 36 | 0 12 | transparent | ink-soft |
| danger | 40 | 0 16 | danger-soft | danger |

- 图标与文字间距 8；图标 16–18。
- 仅图标：40×40 圆形；编辑器顶栏 36×36。
- 禁用：opacity 0.4，`cursor: not-allowed`，不改变颜色。
- 加载：图标位置出现旋转环，保留原宽度，避免布局跳动。

### 6.2 分段控件 Segmented

- 轨道：`surface-2`，高度 40，内边距 4，圆角 pill。
- 选中项：`surface` 底 + 轻阴影 + ink 文字；未选：ink-mute。
- 用于书架筛选、主题选择、平台分组。
- 选项 ≤ 5 个；更多选项改用下拉胶囊。

### 6.3 输入框

- 单行：高度 44，pill，`surface-2` 底，无描边；聚焦时 2 px accent 外环。
- 多行：圆角 24，内边距 16，最小高度 120。
- 标签在输入框上方，13/500 ink-soft；错误文案在下方 12/500 danger。
- 占位符 ink-mute，不得作为唯一说明。

### 6.4 卡片

- 圆角 28，surface 底，1 px line，内边距 20–28。
- 卡片内不再嵌套卡片；需要分组时用细线或 surface-2 区块。
- 作品卡：封面 4:5，平涂底色 + 排版书名；不使用图片也必须好看。
- 图片书封：圆角 20，图片铺满 4:5；底部仅叠一条 `cover-scrim` 平涂信息带承载题材、书名、作者。禁止用渐变蒙版过渡。
- 设定识别色块：圆形或 20 px 圆角，文字与图标使用 `on-cover`；颜色同时配名称或类型文字，不单独承载含义。

### 6.5 对话框与抽屉

- 桌面：居中，最大宽 520，圆角 32，内边距 28。
- 手机：底部抽屉，圆角顶部 28，最大高 90dvh。
- 标题 20/600，说明 13/ink-soft；底部动作右对齐，主按钮在右。
- Esc 关闭；关闭前若表单脏，二次确认。
- 焦点锁定；打开时聚焦第一个输入或关闭按钮。

### 6.6 状态与反馈

- 保存状态使用小型胶囊：已保存（accent-soft/accent）、保存中（surface-2/ink-soft）、未保存（gold 淡底）、冲突（danger-soft/danger）。
- Toast：底部居中胶囊，深色 ink 底、paper 文字，4 秒消失；错误 6 秒。
- 空状态：线性图标 + 一句说明 + 一个主操作，不使用插画照片。
- 加载：骨架块使用 surface-2，不做闪光扫光。

### 6.7 图标

- 统一的 1.75 px 线性图标（lucide-react），圆角端点。
- 尺寸：16（行内）、18（按钮）、20（导航）、24（空状态）。
- 不用 emoji、不用多色图标。平台标识用文字缩写色块。

### 6.8 导航

- 桌面：左侧 248 px 侧栏 + 顶部 64 px 栏。侧栏选中项为 accent-soft 胶囊。
- 手机：底部悬浮胶囊导航（书架、新建、设置），距底 16，左右 20；内容区底部留 96。
- 编辑器不使用全局侧栏，独立顶栏 + 大纲栏 + 正文 + 右侧工具面板。
- 页面切换不做整页滑动动画。

### 6.9 章节插画

- 编辑器插画区：跟在正文纸面之后，标题行 + 「插入插画」胶囊 + 画廊。画廊卡片使用 `surface` 底、1 px `line` 描边、圆角 20；缩略图铺满卡片宽度，保持图片原始比例裁切，不做拍立得、投影或倾斜。
- 卡片信息：图注（无图注时显示「未命名插画」）、锚点摘要（正文之前 / 第 N 段之后 · 段落片段）、编辑入口。状态只用文字表达。
- 插画弹窗：图片预览区使用 `surface-2` 底，图片 `object-contain` 居中，最大高度 260；锚点与图注为普通表单字段，删除动作在左侧并使用 danger 胶囊。
- 阅读器插画：图片宽度占满正文栏，最大高度为可视正文高度的 60%，圆角 14，底色取当前阅读主题的次级底色；图注 0.7em、居中、使用主题次级文字色。禁止滤镜、渐变蒙版、边框装饰。
- 插画不改变正文排版的重心：图片与图注作为独立 figure 参与分页，不在文字后方铺底，也不做行内环绕。

### 6.10 账号、成员、账号安全与整书迁移

- 账号头像：直径 28–44 的圆形平涂色块，取 `AVATAR_COLORS`；首字母/首字使用 `--on-cover`，不用图片或 emoji。账号名与 `@handle` 分两行，handle 使用 ink-mute、10–11 px。
- 登录页：桌面双栏，左侧为品牌与产品说明（`bg-accent`、`text-on-accent`），右侧为表单卡片；手机隐藏品牌侧栏，只留品牌标识、表单与本机账号说明。登录与注册用同一页面内的分段胶囊切换，不跳新页。
- 作者与读者都可注册：登录页与注册表单必须明确说明「作者与读者都可注册」，注册后由作品所有者按账号邀请；空书架也保留同义提示，避免读者误以为注册失败。
- 表单字段使用标准胶囊输入；错误信息紧贴字段下方，文案说明原因与下一步，不用大面积红色。
- 设置页「账号安全」卡片：三个密码胶囊输入（当前密码、新密码、确认新密码）与「更新密码」secondary 胶囊；卡片尾部说明「密码只以加盐哈希保存在本机」。成功后 Toast 说明其他会话已退出，并清空输入。
- 成员卡片：作品页右栏卡片，列表项为「头像 + 姓名/handle + 角色」。所有者看到角色下拉胶囊与移除图标；其他成员只看到文字角色徽标。角色下拉高度 32，移除为 32×32 圆形 ghost，悬停使用 danger-soft。
- 邀请表单：账号输入 + 角色下拉同排，下方一句角色权限说明；「添加成员」为 secondary 胶囊。必须说明「对方需先在本机注册账号，密码无法代为设置」。
- 协作徽标：书架卡片用 `· 协作 · 编辑` 这样的文字后缀，不能只用颜色；只读成员的作品不显示写作入口。
- 整书导入：书架标题行与空状态各有一个 outline 胶囊「导入整书」，隐藏的文件输入接受 `.json,application/json`。导入期间按钮进入加载态并禁用，成功后 Toast 报出书名、章节数与插画数，并跳转到新作品；失败 Toast 使用 danger 变体。
- 导出面板按「阅读副本」与「无损备份」分组：TXT / Markdown / 网页 HTML 在前，JSON 在后。网页项副文案「单文件，含封面与插画」；JSON 项明确「含封面、设定与插画，可再导入」；TXT / Markdown 保留「不含设定与插画」。
- 404：品牌标识 + 等宽 `404` + 一句说明 + 「返回书架」主胶囊，居中留白；不显示默认英文 Next.js 404。

### 6.11 单文件网页导出

- 导出页面是独立阅读版式，不复用工作台外壳：无侧栏、无按钮群、无编辑控件，只保留书名、作者、简介、目录、正文与章节导航。
- 版式：桌面正文栏最大宽 720，居中，衬线正文字体，段首缩进 2em，两端对齐；行高 1.9–2.0，段距约 0.9em。手机左右留白 20，字号不小于 17。
- 书封保持 4:5；有图时整幅铺满并在底部压一条平涂深色信息带，不使用渐变蒙版。无图时使用作品底色平涂版式。
- 目录用细线分隔的列表，卷标题为小号大写感标签，章节行右侧显示字数；移除浏览器默认序号与下划线。
- 插画以 figure 呈现：宽度占满正文栏，最大高度 60vh，圆角 8–14，图注居中、次级文字色。禁止投影、倾斜、滤镜与渐变。
- 主题：默认浅色纸面；`prefers-color-scheme: dark` 时切换为深色中性底与低对比文字。颜色全部写成自包含 CSS 变量，不引用工作台样式表。
- 打印：A4 页边距，隐藏目录与返回链接，卷首另起一页，正文不被插画截断。页面不包含 JavaScript、外部字体、外链图片或表单。
- 所有用户文本必须转义；文件名可读但下载头不得注入换行或引号。

## 7. 页面布局规范

### 7.1 书架

```
顶栏：品牌 | 面包屑 | 搜索胶囊 | 主题 | 账号头像
侧栏：导航 + 最近作品 + 新建作品
主区：
  标题行（问候 / 书架 / 导入整书 / 新建）
  数据条（今日字数 / 累计字数 / 在写作品）
  继续写作卡（宽，左文右按钮）
  筛选行（状态分段 + 搜索 + 数量）
  作品网格（桌面 4 列，平板 3 列，手机 2 列；协作作品带角色文字标记）
```

网格间距 20；卡片封面高宽比 4:5。手机端卡片信息只保留书名、字数、状态。

### 7.2 作品详情

```
面包屑 / 返回
作品头部卡：封面 + 书名 + 状态 + 简介 + 统计 + 主操作
双栏：
  左（8）：分卷目录（卷头 + 章节行）
  右（4）：作品信息、目标进度、协作成员、导出、归档
```

章节行为 56 px 高，序号等宽，悬停显示操作。手机端右栏移到目录下方。

角色门控：

- 所有者：显示全部写入与成员控件。
- 编辑：显示写作、卷章、作品资料控件；成员卡片只读。
- 评论 / 阅读：隐藏写入控件，章节链接指向手机预览；保留导出面板。

### 7.3 编辑器

```
顶栏 56：返回胶囊 | 作品 / 卷 面包屑 | 保存状态 | 字数 | 专注 | 预览
主体：
  大纲 272（可收起）
  正文 minmax(0, 760) 居中，纸面 surface
  工具面板 360（≥1280 常驻，以下为右侧抽屉）
底栏 40：字数 · 段数 · 阅读时长 · 最后保存 · 目标进度
```

正文纸面高度撑满视口，内部滚动；标题与正文在同一列，标题输入无边框。手机端：大纲为左抽屉，工具面板为右抽屉，底栏精简为字数与保存状态。正文纸面下方接插画管理区；文章顶栏的「插画」胶囊显示本章数量，点击滚动到该区域。

### 7.4 手机预览

```
舞台（独立页面，深色舞台 #121311，不随工作台主题）
顶栏：返回写作 | 当前作品 | 设置
左栏 300：平台列表 + 阅读设置
中央：设备 393×852，按可用空间缩放（0.55–1.0）
设备下方：章节选择 + 翻页提示
手机：舞台占满，左栏改为底部设置抽屉
```

设备内只渲染三个部分：状态栏、平台导航、内容与页脚；手势条固定在底部。预览界面左上或设置底部标注「界面模拟，非官方客户端」。

### 7.5 登录与注册

```
桌面：双栏，最大宽 1040
  左：品牌 + 一句话定位 + 三项说明（作者与读者都可注册、角色边界、网页 / JSON 导出）
  右：surface 卡片（segmented 登录/注册 + 表单 + 提交胶囊 + 本机账号说明）
手机：单栏，品牌在上，表单卡片占满可用宽度，底部保留说明
```

- 注册字段：账号、笔名（可选）、密码、确认密码；登录字段：账号、密码。
- 账号自动转小写并去掉前导 `@`；错误提示不区分「账号不存在」与「密码错误」。
- 未登录访问任何工作台页面跳转 `/login`；登录成功后回到 `/library`。
- 本机说明必须可见：账号与密码只存在本机、没有邮箱与找回入口。
- 注册模式额外说明：注册后既可以开始写作，也可以等待作品所有者按账号邀请，成为只读读者。

## 8. 平台模拟规范

平台差异集中在四层：**品牌色、导航结构、正文排版、页脚信息**。不做假功能（如打赏、广告），避免误导。

| 平台 | 品牌色 | 默认字体 | 默认字号 / 行高 | 导航 | 页脚 |
| --- | --- | --- | --- | --- | --- |
| 起点读书 | `#C6472E` | 宋体 | 18 / 1.90 | 返回 + 书名 + 目录 | 页码 + 细进度线 |
| 番茄小说 | `#E85D2A` | 无衬线 | 18 / 1.90 | 返回 + 书名 + 目录 | 页码 + 「下一章」胶囊 |
| 晋江文学城 | `#3E7A52` | 宋体 | 17 / 1.95 | 居中章节名 + 目录 | 页码 + 「本章评论」占位 |
| 微信读书 | `#2F6BEA` | 无衬线 | 17 / 1.85 | 极简：书名 + 更多 | 百分比 + 页码 |
| 七猫小说 | `#D99A16` | 无衬线 | 19 / 1.95 | 返回 + 书名 + 目录 | 页码 + 大号「下一章」 |

规则：

- 平台品牌色只用于强调、进度、按钮，不铺满正文背景。
- 字体/字号/行高默认值可被用户覆盖，覆盖按平台独立记忆。
- 平台导航中的「目录」可用；「更多」「评论」不得触发假交互，可展示静态占位说明或禁用。
- 页脚页码格式：`当前页 / 总页数`；微信读书额外显示章节内百分比。
- 平台模拟仅用于排版检查；真实发布格式以平台为准。

### 8.1 设备规格

- 屏幕逻辑尺寸：393 × 852。
- 外框：10 px 黑色边框，44 px 圆角。
- 状态栏：32 px；打孔摄像头居中，直径 10。
- 手势条：底部 20 px 区域内 112 × 4 胶囊，颜色随主题反色。
- 阅读区：左右页边距 18/22/28 三档，上下留白 20。
- 正文：首行缩进 2em，两端对齐，段间距 0.8em，章节标题居中。

### 8.2 分页与翻页

- 分页基于 CSS 多栏排版真实测量，禁止按字数估算。
- 当前页、总页数、章节进度必须随字号、行高、边距、字体、平台、设备缩放实时更新。
- 翻页交互：点击右侧 65% 区域下一页；左侧 35% 上一页；横向滑动阈值 40 px；键盘 ←/→/空格。
- 翻页动画仅「平移」与「无动画」两种，保持平面感；尊重减少动效设置。
- 末页继续翻进入下一章；首翻回到上一章最后一页；章节切换后页码归零。
- 选中文字时不触发翻页。
- 章节插画在锚点段落后参与分页；图片高度不超过正文可视高度的 60%，`break-inside: avoid`；图片加载完成后重测页数，避免半页空白或图片截断。

## 9. 文案规范

- 语气：安静、具体、不卖萌、不训导。
- 动作使用动词：继续写作、新建作品、保存版本、导出 TXT。
- 避免「亲」「哦」「呀」等口癖；避免感叹号堆叠。
- 空状态写下一步，不写空泛鼓励。例：「还没有作品。先为它起一个名字。」
- 错误写原因与动作。例：「保存失败，已保留本地草稿。将在网络恢复后重试。」
- 中文与数字之间留半角空格；中英文标点不混用。
- 所有界面文案不含 emoji。

## 11. 验收口径

- 任意页面截图不出现渐变、emoji、彩色投影、玻璃效果。
- 按钮、输入、标签、导航选中态均为一致的胶囊语言。
- 书架、作品、编辑器、预览、设置五个页面在同类元素上使用同一组件；登录页与 404 也遵循同一胶囊与令牌体系。
- 深色模式下所有文字对比度达标，无纯黑卡片叠纯黑背景。
- 手机预览五个平台可以一眼区分，但都保持同一信息结构。
- 章节插画卡片与阅读器 figure 保持平涂与细线，无拍立得、投影、滤镜或渐变；390 宽下插画弹窗与画廊无横向溢出。
- 登录页、成员卡片、导入按钮与 404 在 1440 与 390 宽均无横向溢出；头像色块文字使用 `--on-cover`，深色模式仍可读。
- 键盘可完成主要操作，焦点始终可见。
